# Ритм v0.8.1 — планировщик

## Что изменилось
- Добавлены предупреждения о пересечении задач при создании и переносе, без запрета сохранения.
- Исправлено обновление текущей даты, если приложение остаётся открытым после полуночи.
- Добавлены отсутствовавшие SVG-иконки PWA; исправлена версия кеша Service Worker.
- Главная страница сфокусирована на расписании выбранного дня.
- Дата в заголовке открывает календарный выбор.
- Под датой отображается неделя из семи компактных кнопок. Нажатие на день открывает его расписание.
- Убраны режимы День / Неделя / Месяц / Год и прежняя строка календаря.
- Кнопка «Р» открывает меню с настройками.
- Переключение светлой/тёмной темы и импорт/экспорт резервной копии находятся в настройках.
- Исправлена мобильная ширина карточек задач и доступность кнопок сохранения в формах.

## Данные и совместимость
- Используется прежняя локальная база IndexedDB: `ritm-local`, хранилище `app`.
- Формат данных не менялся. Миграция и удаление пользовательских данных не выполняются.
- Задачи, списки, дневник и другие разделы остаются в локальном хранилище устройства.
- Для переноса данных на другой адрес или устройство используйте экспорт/импорт в настройках.

## Запуск на компьютере
1. Распакуйте архив.
2. В Windows запустите `run-ritm.bat`.
3. Для установки приложения на iPhone или компьютере используйте опубликованный HTTPS-адрес.

## Важно
- Для PWA требуется HTTPS.
- Локальные данные браузера не синхронизируются между устройствами.
- Семейный обмен остаётся демонстрационным, облачной синхронизации в этой версии нет.
