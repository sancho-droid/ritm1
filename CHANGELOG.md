# История версий

## v0.7.0
- Главная страница переработана вокруг дневного планировщика.
- Добавлена неделя с семью компактными кнопками дат; выбор дня обновляет расписание.
- Дата в заголовке открывает выбор даты.
- Убраны переключатели День/Неделя/Месяц/Год и старая строка календаря.
- Логотип «Р» открывает меню с настройками; переключение темы и импорт/экспорт перенесены в настройки.
- Исправлена мобильная сетка карточки задачи, из-за которой карточка могла сжиматься/растягиваться.
- Модальные окна и кнопки подтверждения подняты над нижней навигацией; нижняя панель действий остаётся доступной при прокрутке формы.
- Обновлён кеш Service Worker. Структура IndexedDB и данные не изменялись.


## v0.5.0
- Перенос задачи теперь открывает месячный календарь с индикацией занятости дней.
- При выборе даты показывается список задач этого дня с временем и длительностью.
- Добавлена проверка пересечений по времени с учётом длительности задач; перенос можно подтвердить несмотря на предупреждение.
- Исправлен повторный перенос отдельного выполнения повторяющейся задачи: новое место обновляет исходную запись выполнения, не создавая оставшуюся копию.
- Нативные поля даты и времени адаптируются к светлой и тёмной системной теме приложения.
- Обновлён кеш Service Worker.

## v0.4.2
- Длительность задачи теперь задаётся отдельно часами и минутами; в базе по-прежнему хранится общее количество минут, поэтому старые задачи совместимы.
- В карточке задачи добавлены быстрые действия: редактировать, перенести и удалить.
- Перенос открывает окно выбора даты и времени. Для повторяющейся задачи переносится только выбранное выполнение.
- Удаление через карточку требует подтверждения. Удаление одного повторения не удаляет всю серию.
- Обновлена версия кеша Service Worker.


## v0.4.1
- Исправлено сохранение выбранного режима календаря (день/неделя/месяц/год) и выбранной даты после обычного обновления страницы.
- Для переходов на страницу включена загрузка актуального HTML с сервера с офлайн-резервом.
- Обновлена версия кеша Service Worker и проверка обновлений.


## v0.4
- Добавлены режимы календаря: день, неделя, месяц и год.
- Добавлен переход к любой дате через календарный выбор.
- Добавлены повторения: ежедневно, выбранные дни недели, ежемесячно, ежегодно и через интервал дней.
- Каждое повторяющееся выполнение получает отдельный статус; отметка не затрагивает остальные даты.
- Добавлено редактирование повторения: только одно выполнение, это и следующие, всё расписание.
- Для повторений предусмотрена дата окончания; 29/30/31 число корректно адаптируется к длине месяца, 29 февраля в невисокосный год приходится на 28 февраля.
- Старые разовые задачи сохраняются без преобразования; данные выполнения хранятся в IndexedDB.
- Обновлён кеш Service Worker.

## v0.6.1 — мобильный интерфейс и личные модули
- Добавлена мобильная нижняя навигация с учётом safe-area iPhone.
- Переработаны отступы, календарь, карточки задач, формы и модальные окна для узких экранов.
- Добавлены разделы «Дневник» (текст, фото, аудиофайлы), «Привычки» и «Детский режим».
- В детском режиме доступны личные дела, журнал пополнений/расходов и цель накопления.
- Существующая IndexedDB `ritm-local` не менялась по имени и версии; старые записи мигрируют автоматически без удаления.
- Экспорт/импорт резервной копии включает новые разделы.
- Обновлён кэш Service Worker и манифест PWA.

### Границы этой сборки
- Семейные события и списки пока работают локально на одном устройстве. Для синхронизации между телефонами необходим отдельный серверный контур и авторизация участников.
- Публикация PWA для установки на iPhone требует HTTPS-хостинга. Эта сборка сама по себе не размещает приложение в интернете.
- Сквозное шифрование базы, PIN-блокировка и защищённое облачное резервирование остаются отдельной задачей и не включены в эту сборку. Локальное хранение не означает шифрование.

## v0.8.0 — планировщик
- Убраны стрелки переключения дней; дата в шапке открывает календарь.
- В ленте недели число отображается над сокращённым названием дня; горизонтальный свайп переключает недели.
- Форма задачи упорядочена: название, дата, начало, окончание, длительность, категория, повторение, заметки, публикация семье.
- Добавлено автоматическое согласование времени окончания и длительности.
- Длительность отображается под временем начала в карточке.
- Действия задачи объединены в меню кнопки-карандаша.
- Добавлено перетаскивание задач между позициями расписания и из раздела без времени; пересечения предупреждаются, фиксированные задачи автоматически не сдвигаются.
- Раздел задач без времени отделён тонкой линией без заголовка.
- Сохранена существующая IndexedDB и структура пользовательских данных.
